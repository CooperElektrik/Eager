# LSP Features

Editor language intelligence features provided by `eager-script-lsp`.

| Feature | Module | Description |
|---------|--------|-------------|
| [Completion](completion.md) | `eager_script_lsp.features.completion` | Auto-completion for scenes, characters, and variables. |
| [Diagnostics](diagnostics.md) | `eager_script_lsp.features.diagnostics` | Real-time syntax and semantic validation. |
| [Hover](hover.md) | `eager_script_lsp.features.hover` | Inline documentation and hover inspection. |
| [Navigation](navigation.md) | `eager_script_lsp.features.navigation` | Go-to-definition, reference discovery, and document outline. |
| [Code Lenses](lenses.md) | `eager_script_lsp.features.lenses` | Visual action lenses and scene reference counters. |
| [Refactor](refactor.md) | `eager_script_lsp.features.refactor` | Symbol rename and code transformation assists. |
| [Semantic Tokens](tokens.md) | `eager_script_lsp.features.tokens` | Semantic highlighting for language tokens. |
